# 央国企资金链数据管理规则

本板块是“当前可投的湖北 2027 届校招控制链”，不是央国企百科或永久企业名录。公开数据由 `activeOwnershipData` 按上海日期计算；原始控制证据和历史岗位保留在源数据中供审计，失效记录不再进入公开有效链。

## 准入

1. 至少有一条明确指向湖北用人单位的 2027 届开放岗位，且岗位有 HTTPS 投递入口。集团主页、往届校招页和仅有企业名称的聚合信息不能替代投递入口。
2. 用人单位必须指向可核验的法人节点；分公司作为 `HiringUnit`，不得充当独立法人。控制边应有年报、交易所、国资委或企业官方披露证据，招聘证据不能证明股权关系。
3. 录入 `verifiedAt`、`deadline`、招聘证据及投递入口。人数未披露写“若干/未披露”；截止日未披露写“未披露”，不得把高校公告过期时间冒充投递截止日。
4. 上级法人仅作控制关系背景，其按钮明确标注“下属湖北单位投递”，链接指向该链的有效湖北岗位，不暗示上级法人自行招聘。

## 更新与淘汰

- 每日运行 `npm run sync:ownership-recruitment`，生成 `data/ownership-lifecycle.json`，记录有效岗位、用人单位和淘汰原因；随后运行采集、测试、数据校验和构建。发布流程只发布验证通过的数据。
- 明确截止日的岗位在截止日当天仍可展示，次日自动退出。若一条链没有任何有效岗位，整条链从公开板块移除；若仍有其他有效岗位，只淘汰到期岗位。
- 未披露截止日的岗位，距最近一次人工确认超过 7 个上海自然日即自动退出公开展示。再次确认官方岗位仍可投后，更新 `verifiedAt`，才可重新进入。例行 HTTP 200 或站点首页存活不能自动延长确认日期。
- 官方页面明确宣布结束、岗位下线或投递按钮关闭，经复核后把岗位状态改为 `已结束` 并记录证据；不要仅因 403、404、405、验证码、超时或采集失败判定结束。这些情况进入待复核队列，保留审计记录；未知截止日的 7 天期限仍适用。
- 任何 2027 届湖北岗位重新开放时，按新公告重新核验并录入，不能复用往届岗位链接或旧的 `verifiedAt`。到期记录仅留在源数据用于历史追溯，不作为公开数据库的有效企业数。

## 验收

运行 `npm test`、`npm run validate:data`、`npm run build:pages`。检查公开页面有效链数量、每条链的投递按钮及截止日次日退出行为；同步报告中的淘汰原因必须可读。若全部岗位失效，板块显示空状态，不能为了维持数量保留过期链。
